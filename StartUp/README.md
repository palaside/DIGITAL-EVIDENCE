# StartUp Runtime

โครงสร้างตามลำดับ:

INPUT → ANALYZE → CLASSIFY → GENERATE FILES → GENERATE PROJECT → INSTALL DEPENDENCIES → BUILD → START

## ใช้งาน
1. แตก ZIP
2. กด `INSTALL_TO_TARGET.bat` เพื่อคัดลอกไปที่ `D:\Project\หลักฐานดิจิทัล  DIGITAL EVIDENCE\StartUp`
3. เข้าโฟลเดอร์ปลายทาง
4. วางรูปใน `GENERATE_PROJECT\chat-evidence-processor\inputs`
5. กด `Start.bat`
